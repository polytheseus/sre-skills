What it's like

> checkout is throwing 5xx since about 14:02, can you look?

Reading before guessing. Error rate on checkout went from 0.2% to 31% at 14:02:40. Deploy checkout v2.31 finished at 14:01:55; nothing else changed in that window. New error in the logs since then: PG connection pool exhausted (max=20).

Impact: about a third of checkouts failing, all regions.
Likely cause: v2.31 (pool size config changed from 50 to 20).

Proposed mitigation (needs your OK):

kubectl rollout undo deployment/checkout -n shop

Blast radius: checkout pods only, rolling, no downtime. Undo: kubectl rollout undo again. I'll draft the status update while you decide.

An illustrative session. The skills ask before any command that changes production.
